# WHMCS Module
> Модуль, разработанный для движка WHMCS 8+, который позволяет создавать счета и осуществлять выдачу цифровых услуг

---
#### Инструкция
##### 1. Установка аддона
- 1.1. Переместите папку "modules" в корень вашего сайта (```/```)
- 1.2. Перейдите на вкладку «Настройки» -> «Apps & Integrations» -> «Search», введите в поле поиска «Monee» и нажмите «Activate» (```/admin/apps/search```)  
##### 2. Настройка аддона
- 2.1. После активации модуля WHMCS перенаправит на страницу настройки модуля. Если этого не произошло, перейдите на вкладку «Настройки» -> «Платежные шлюзы» (```/admin/configgateways.php```)  
- 2.2. Введите любое отображаемое название, в поле «UUID мерчанта» введите UUID, который можно получить в настройках мерчанта  
![image](https://monee.s3.de.io.cloud.ovh.net/docs/img/modules/whmcs/1.jpg)  
- 2.3. Готово. Теперь при оплате клиент сможет выбрать способ оплаты «Monee»
